# security

## что считать уязвимостью

- утечка токенов и client_id из логов или сети
- выполнение произвольного кода через zapret bat и распаковку zip
- обход sandbox tauri и capabilities
- xss в webview через данные soundcloud

## как сообщить

- telegram: https://t.me/aether_player личным сообщением
- или github security advisory в репозитории

не открывай публичный issue, если проблема позволяет выполнить код или увести данные

## что не считается

- протухший client_id это известное ограничение api, см `md/BUGS.md`
- блокировки провайдера это не уязвимость
- отсутствие подписи у сборок, пока проект не публикуется в сторах

## версии

поддерживается только последний релиз 0.1.x
