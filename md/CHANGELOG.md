- `AGENTS.md` и `docs/ai/skills` - контекст и плейбуки для работы с ии-агентами
- ci на github actions: typescript, сборка фронта, cargo check
- issue forms, pr template, dependabot
- `CONTRIBUTING.md`, `SECURITY.md`, `.editorconfig`, `.gitattributes`
- `docs/public/build.md`
- roadmap и список багов приведены к реальному состоянию
- страница артиста: hero с фоном, статистикой и действиями, 6 табов, блоки ваше с артистом, релизы, жанры
- скелетоны шапки и секций на странице артиста, данные грузятся по секциям
- вкладки limit и offset у команд артиста, страница больше не тянет все страницы soundcloud разом
- `invokeCmdStrict` для страниц, которым нужен код ошибки вместо null
- локальный кэш треков: temp для воспроизведения и offline для ручного сохранения
- выбор качества `best`, `high`, `medium`, `low`, по умолчанию `best`
- `sc_anon` как fallback при 401 и отсутствии потока
- офлайн-сохранение трека из контекстного меню и плейлиста целиком
- вкладка аудио с подразделами воспроизведение и кэш
- rodio обновлен до 0.23.0, cpal до 0.18.2
- нормализация громкости по RMS с ограничением пика
- gapless через очередь player и авто-переход по событию track:auto-advanced
- кроссфейд с настраиваемой длиной
- 10-полосный biquad эквалайзер с преампом
- регулировка скорости 0.5..2.0 без изменения высоты тона, WSOLA с поиском похожего окна
- отдельная регулировка питча -12..+12 полутонов через ресемплинг
- режим linked: скорость и питч синхронизированы как винил, чистый resample без time-stretch
- кнопка gauge в большом плеере с попапом скорости и питча, открывается снизу
- скорость и питч убраны из настроек, управление только через gauge-попап
- кастомные слайдеры с тиками и анимацией вместо нативного range
- gapless и crossfade переведены на два player-а и equal-power кривые
- отмена устаревших переходов через transition generation
- переключатель переходов с плавающим индикатором и выплывающей длиной кроссфейда
- длина кроссфейда на общем кастомном слайдере
- визуализация спектра текущего трека в эквалайзере
- график АЧХ с перетаскиваемыми точками полос
- отдельный подраздел эквалайзера
- список фильтров: тип, частота, gain, Q, включение и удаление
- сглаженная волна спектра вместо колонок
- полосы эквалайзера двигаются по частоте и усилению, с подсказкой при драге
- числовые поля фильтров без стрелок, список растет по высоте без внутреннего скролла
- эквалайзер сворачивается при выключении и разворачивается с анимацией
- пресеты эквалайзера и динамический индикатор уровня
- выбор устройства вывода через cpal, карточками с полным именем драйвера и иконкой
- вкладка аудио в настройках: режим потока или кэша, качество, автосохранение, размеры, лимит, очистка
- выбор устройства вывода звука
- режим только воспроизведения без записи трека на диск
- в roadmap добавлены нормализация громкости, бесшовное воспроизведение и кроссфейд
- иконки кэша перед названием трека: `download-cloud` для офлайн, `database` для временного кэша

### changed

- http слой переехал с `reqwest`/rustls на `wreq` с эмуляцией отпечатка браузера, chrome по умолчанию и firefox как второй профиль на 403
- звук облака: json и медиа ходят с браузерными `sec-fetch` заголовками, ua больше не задаётся руками
- rust обновлён до 1.99.1, для сборки boringssl нужен cmake
- прокси: явный прокси из настроек важнее системного из windows, очистка настроек откатывается на системный, а не на прямое соединение
- dns: хосты резолвятся через doh (cloudflare и google), при недоступности doh запрос уходит в системный резолвер
- кэш: уровень качества, который упал для трека, не дергается 10 минут, следующая попытка сразу идет уровнем ниже
- анонимный путь больше не перевыпускает `client_id` на 404, только на 401 и 403
- лейаут: `main` стал `flex flex-col`, страницы сами владеют скроллом через `flex-1 min-h-0`
- удалён `useSmoothScroll`, вместо него обычные ref
- табы артиста перерисовываются сразу, кэш страницы живёт 5 минут и обновляется в фоне
- ошибка 401 на странице артиста показывается баннером, а не редиректом в поиск
- `get_user_tracks`, `get_user_reposts`, `get_user_playlists` отдают одну страницу с `has_more`
- табы артиста сократились до все, треки, релизы, плейлисты, репосты
- hero артиста переделан под референс: круглый аватар без фона, статистика строкой, shuffle иконкой
- популярное в обзоре стало горизонтальной каруселью, похожие артисты списком внизу страницы
- вкладка треки переключает популярные и новые без клиентской сортировки, каждый список кешируется
- репосты поддерживают альбомы и плейлисты, а не только треки
- переход между табами анимируется через view transitions, аватар и имя уменьшаются и растут
- поиск: новый вид фильтров с бегущим индикатором и капсулой, анимация появления строк
- sccache и lld убраны из репозитория в локальный `~/.cargo/config.toml`
- версия react в документации приведена к 19
- `playTrack` играет файл из кэша, следующий трек греется через `track_preload`
- движок больше не держит аудио в памяти и определяет формат для seek
- play, seek и смена трека ставят источник в новый player вместо `clear()` под локом, команды не могут зависнуть на мертвом устройстве
- тик позиции останавливается на паузе и стопе, а на простое просыпается раз в 200 мс
- temp-кэш держит 12 треков вместо 3, prev и next больше не перекачиваются
- режим без кэша запоминает последние треки в памяти, повтор играет сразу
- прогресс кроссфейда считается по аудио-клоку, а не по стенным часам
- нормализация громкости анализирует первые 40 секунд вместо полного декода на ipc-потоке
- эквалайзер не обрабатывает нулевые полосы и не считает преамп на каждый сэмпл
- нормализация громкости переведена с RMS на LUFS по BS.1770: K-weighting, блоки 400 мс, абсолютный и относительный гейтинг
- true peak считается 4x oversampling по блокам, потолок усиления -2 dBTP, клиппинг после буста исключен
- цель нормализации настраивается слайдером от -18 до -9 LUFS, по умолчанию -14 как в стриминге
- замер громкости убран с пути воспроизведения: трек стартует мгновенно, замер считается в фоне и применяется плавно
- замеры хранятся в `loudness.json` рядом с кэшем, повтор и рестарт не декодируют трек заново
- усиление нормализации живет в слоте, его можно менять на ходу и на seek без пересборки трека
- версия стора 18 с миграцией цели нормализации
- фоновая обложка и её размытие сведены в один объект `coverBackground`, версия стора 19, тумблер общий для внешнего вида и производительности
- размер фоновой обложки берётся из общего потолка качества, порог 24 убран
- слой размытия рисуется с запасом за границами окна, края больше не темнеют
- фоновая обложка растянута на всё окно без отступов и скруглений, тайтлбар стал полупрозрачным и показывает её сверху
- шум и зерно лежат на всём фоне, а не только на колонке контента

### fixed

- фоновая обложка грузится по цепочке кандидатов и на старте, битый t500 больше не оставляет пустой фон
- старая обложка не залипает, если все кандидаты нового трека не открылись
- слой кроссфейда снимается по завершении анимации, а не висит до следующего трека
- подпись `яркость` у слайдера заменена на видимость фона
- драг ползунков размытия больше не перерисовывает сайдбар и плеер-бар
- закрыт незакрытый code fence в README
- битая ссылка на build.md в docs/public
- быстрые клики по трекам больше не перебивают друг друга: старый запрос play отбрасывается по номеру в rust, новый звук не глушится
- конец трека определяется и по пустому плееру, так что трек с пустой или завышенной длительностью не зависает на последней секунде
- длительность берется из самого файла, если метаданные soundcloud пустые или короче
- поток больше не растягивает position-tick на каждый рендер: подписки в `usePlayerProgress` ставятся один раз
- повторный seek на сломанный файл больше не откатывает трек в начало молча, ошибка уходит на фронт
- вытеснение temp-кэша не удаляет играемый трек и сортирует по mtime, а не по accessed
- переключение качества поверх сохраненного offline файла не затирает копию и не качает трек заново на каждом play
- два одновременных сохранения в offline больше не пишут в один файл, копия идет через `.part` и rename
- обрезанная загрузка без content-length и недописанный `.part` больше не оседают в кэше как целый трек
- повторное включение анонимного client_id больше не залипает на 30 секунд после первой ошибки
- анонимный клиент не рвет большой трек по общему таймауту 20 секунд
- ошибка старта трека останавливает предыдущий вместо тихого продолжения его игры
- mute больше не слетает на gapless и crossfade
- очередь перехода и `queue_next_track` больше не гоняются за unqueue: переход резервирует слот до сборки источника
- 5 последовательных запросов похожих треков в конце очереди заменены параллельными, конец очереди больше не висит
- флаг `autoAdvancePending` сбрасывается, если очередь успела измениться, иначе детект конца трека замолкал навсегда
- настройки кэша: размер и инвентарь считаются вне главного потока, ui не замирает
- таймкод и полоса прогресса сбрасываются сразу при переключении на некэшированный трек, а не после старта
- seek, сделанный во время загрузки, больше не применяется к следующему треку
- длительность, взятая движком из файла, доезжает до фронта, если у трека пустое поле duration
