# changelog

все значимые изменения проекта

формат основан на [keep a changelog](https://keepachangelog.com/)

## [unreleased]

### added

- `AGENTS.md` и `docs/ai/skills` - контекст и плейбуки для работы с ии-агентами
- ci на github actions: typescript, сборка фронта, cargo check
- issue forms, pr template, dependabot
- `CONTRIBUTING.md`, `SECURITY.md`, `.editorconfig`, `.gitattributes`
- `docs/public/build.md`
- roadmap и список багов приведены к реальному состоянию
- страница артиста: hero с фоном, статистикой и действиями, 6 табов, блоки ваше с артистом, релизы, жанры
- скелетоны шапки и секций на странице артиста, данные грузятся по секциям
- вкладки limit и offset у команд артиста, страница больше не тянет все страницы soundcloud разом
- `invokeCmdStrict` для страниц, которым нужен код ошибки вместо null
- локальный кэш треков: temp для воспроизведения и offline для ручного сохранения
- выбор качества `best`, `high`, `medium`, `low`, по умолчанию `best`
- `sc_anon` как fallback при 401 и отсутствии потока
- офлайн-сохранение трека из контекстного меню и плейлиста целиком
- вкладка аудио с подразделами воспроизведение и кэш
- выбор устройства вывода через cpal, карточками с полным именем драйвера и иконкой
- вкладка аудио в настройках: режим потока или кэша, качество, автосохранение, размеры, лимит, очистка
- выбор устройства вывода звука
- режим только воспроизведения без записи трека на диск
- в roadmap добавлены нормализация громкости, бесшовное воспроизведение и кроссфейд
- иконки кэша перед названием трека: `download-cloud` для офлайн, `database` для временного кэша

### changed

- лейаут: `main` стал `flex flex-col`, страницы сами владеют скроллом через `flex-1 min-h-0`
- удалён `useSmoothScroll`, вместо него обычные ref
- табы артиста перерисовываются сразу, кэш страницы живёт 5 минут и обновляется в фоне
- ошибка 401 на странице артиста показывается баннером, а не редиректом в поиск
- `get_user_tracks`, `get_user_reposts`, `get_user_playlists` отдают одну страницу с `has_more`
- табы артиста сократились до все, треки, релизы, плейлисты, репосты
- hero артиста переделан под референс: круглый аватар без фона, статистика строкой, shuffle иконкой
- популярное в обзоре стало горизонтальной каруселью, похожие артисты списком внизу страницы
- вкладка треки переключает популярные и новые без клиентской сортировки, каждый список кешируется
- репосты поддерживают альбомы и плейлисты, а не только треки
- переход между табами анимируется через view transitions, аватар и имя уменьшаются и растут
- поиск: новый вид фильтров с бегущим индикатором и капсулой, анимация появления строк
- sccache и lld убраны из репозитория в локальный `~/.cargo/config.toml`
- версия react в документации приведена к 19
- `playTrack` играет файл из кэша, следующий трек греется через `track_preload`
- движок больше не держит аудио в памяти и определяет формат для seek

### fixed

- закрыт незакрытый code fence в README
- битая ссылка на build.md в docs/public
