# roadmap

что делаем и в каком порядке. подробная стратегия в `docs/context/20_roadmap.md`

## сейчас - стабильность

- [ ] health check client_id при старте и понятный баннер при 401
- [ ] автоскрейп client_id вместо пересборки
- [ ] разделить таймауты http: api, media, download
- [x] не терять поисковый запрос при быстром вводе и смене таба
- [ ] `AppState` без паники, если нет аудиоустройства
- [ ] single-instance, чтобы два окна не делили один store
- [ ] ErrorBoundary вместо белого экрана
- [ ] position вне общего persist, чтобы не писать стор каждую секунду (частично: интервал записи 1 или 5 секунд из вкладки быстродействие, но позиция всё ещё внутри общего блоба)

## следом - офлайн-кэш

- [x] локальный кэш воспроизведения в temp, без ffmpeg
- [x] ручное офлайн-сохранение трека и плейлиста
- [x] настройка качества, по умолчанию самое высокое
- [x] лимит кэша, LRU, очистка
- [x] `sc_anon` как fallback при 401 и отсутствии потока
- [x] автоматическое офлайн-сохранение по умолчанию выключено

## следом - аудио

- [x] выбор устройства вывода
- [x] режим только воспроизведения без кэша
- [x] нормализация громкости по RMS и пику
- [x] бесшовное воспроизведение через очередь rodio
- [x] кроссфейд с наложением
- [x] эквалайзер с графиком АЧХ и перетаскиваемыми полосами
- [x] спектр текущего трека
- [x] список фильтров с типами, частотой, gain и Q
- [x] регулировка скорости 0.5..2.0
- [ ] LUFS и true peak вместо RMS
- [x] pitch-preserving скорость 0.5..2.0, сделано своим WSOLA с поиском похожего окна, signalsmith-stretch не понадобился

## следом - полировка

- [x] 5 тем оформления
- [x] blur обложки и кастомные пресеты
- [x] лейаут на `flex-1 min-h-0` и единый владелец скролла
- [x] новый поиск: фильтры, капсула, история, подсказки с кэшем
- [x] accent в сайдбаре, фильтрах поиска и контекстном меню
- [ ] focus ring в табах артиста, сайдбаре и контекстном меню
- [x] вкладка быстродействие: флаги по группам, пресеты, качество обложек, fps-метр
- [x] виртуализация длинных списков через `@tanstack/react-virtual`
- [x] горячие клавиши через `tauri-plugin-global-shortcut`
- [ ] локальная подписка на артиста в библиотеке: свой список артистов, без oauth soundcloud
- [x] страница артиста: скрывать пустые разделы, треки, альбомы, плейлисты, репосты
- [x] похожие артисты: `/users/{id}/related`, блок в обзоре, догрузка по offset (курсор у related не нужен)
- [ ] источник похожести кроме soundcloud related, если related пустой или короткий
- [ ] уведомления ОС при смене трека
- [ ] мини-плеер в трее
- [ ] drag-n-drop в очереди
- [ ] кэш метаданных на диск

- [ ] экспорт трека в файл с обложкой и тегами
- [x] отказаться от `wreq`: rustc 1.95 не тянет 0.16, кэш и anon на `reqwest`

- [ ] lyrics
