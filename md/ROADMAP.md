# roadmap

что делаем и в каком порядке. подробная стратегия в `docs/context/20_roadmap.md`

## сейчас - стабильность

- [ ] health check client_id при старте и понятный баннер при 401
- [ ] автоскрейп client_id вместо пересборки
- [ ] разделить таймауты http: api, media, download
- [ ] не терять поисковый запрос при быстром вводе и смене таба
- [ ] `AppState` без паники, если нет аудиоустройства
- [ ] single-instance, чтобы два окна не делили один store
- [ ] ErrorBoundary вместо белого экрана
- [ ] position вне общего persist, чтобы не писать стор каждую секунду

## следом - полировка

- [x] 5 тем оформления
- [x] blur обложки и кастомные пресеты
- [ ] лейаут на `flex-1 min-h-0` и единый владелец скролла (в работе)
- [ ] новый поиск: фильтры, капсула, история (в работе)
- [ ] accent в табах, focus ring, sidebar, dropdown
- [ ] локальная подписка на артиста в библиотеке: свой список артистов, без oauth soundcloud
- [x] страница артиста: скрывать пустые разделы, треки, альбомы, плейлисты, репосты
- [ ] похожие артисты: `/users/{id}/related` с курсорной пагинацией, блок в конце обзора
- [ ] источник похожести кроме soundcloud related, если related пустой или короткий
- [ ] уведомления ОС при смене трека
- [ ] мини-плеер в трее
- [ ] drag-n-drop в очереди
- [ ] кэш метаданных на диск

## потом

- [ ] кэш аудио с лимитом и офлайн
- [ ] discord rich presence
- [ ] lyrics
- [ ] spotify, youtube music, bandcamp
- [ ] единый поиск по источникам

## не делаем

- скачивание треков на диск
