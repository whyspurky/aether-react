# о soundcloud

как aether работает с soundcloud и что это значит для тебя

## как устроено

aether не имеет официального доступа к soundcloud

использует тот же внутренний api что и сам сайт soundcloud в браузере
через те же эндпоинты и с тем же идентификатором

*это значит*

1. aether не связан с soundcloud

2. работает пока работает сам сайт soundcloud

## что доступно

всё что доступно на сайте soundcloud без входа в аккаунт

*работает*

1. поиск треков плейлистов артистов

2. популярное подборка на основе открытых данных

3. моя волна рекомендации из истории прослушиваний

4. профили артистов и их треки

5. плейлисты soundcloud

6. стриминг треков

*не работает*

1. личные плейлисты твоего аккаунта только те что открыты

2. лайки и репосты из твоего профиля

3. загрузка треков

## про качество

soundcloud отдаёт треки в нескольких форматах

*aac 160* максимум без подписки

*aac 96* используется как fallback если 160 недоступен

*mp3 128* устаревающий формат soundcloud от него постепенно отказывается

### про 256 320 и flac

*aac 256* доступен только для подписчиков go plus
он не выходит за пределы самого приложения soundcloud и официальных партнёров

*mp3 320* как отдельный формат на soundcloud не существует
это миф потому что aac 256 по качеству соппастовимо с mp3 320

*flac* на soundcloud не стримится ни в каком виде
оригинал в flac или wav может храниться на сервере но отдаётся только если автор разрешил скачивание

### что использует aether

цепочка такая

1. aac 160

2. aac 96

3. mp3 hls

4. mp3 progressive

это максимум доступного без подписки

## про законность

aether использует публично доступные данные soundcloud

неофициальный клиент
не связан с soundcloud

## если не работает в россии

провайдеры в рф блокируют cdn soundcloud на уровне dpi

*метаданные* поиск списки обложки идут через api soundcloud он не заблокирован

*стриминг* сам звук идёт через cdn он заблокирован

*что делать*

1. в aether есть встроенный режим *zapret* обход блокировок без vpn

первый шаг скачай zapret автоматически или укажи папку вручную

второй шаг выбери стратегию если одна не работает попробуй другую они различаются для разных провайдеров

*важно* прогрев пока zapret успеет перехватить запросы колеблется от одной до десятка минут

2. альтернатива свой *прокси* socks5 или http

3. *самый стабильный вариант* включи vpn на время прослушивания

## ограничения

aether не встраивает vpn или свой сервер пока что

для обхода блокировок используется либо zapret либо твой личный прокси
