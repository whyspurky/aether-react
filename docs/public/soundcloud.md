# о soundcloud

как aether работает с soundcloud и что это значит для тебя.

## как устроено

aether **не имеет** официального доступа к soundcloud. использует **тот же внутренний api**, что и сам сайт soundcloud в браузере — через те же endpoints и с тем же идентификатором.

**это значит:**

- aether **не связан** с soundcloud
- работает, пока работает **сам сайт** soundcloud
- может **сломаться** если soundcloud изменит **внутренний** api

## что доступно

всё, что **доступно** на сайте soundcloud **без входа в аккаунт**:

- **поиск** треков, плейлистов, артистов
- **популярное** — подборка на основе открытых данных
- **моя волна** — рекомендации из истории прослушиваний
- **профили** артистов и их треки
- **плейлисты** soundcloud
- **стриминг** треков

**не работает:**

- **личные плейлисты** твоего аккаунта (только те, что **открыты**)
- **лайки** и **репосты** из твоего профиля
- **загрузка** треков

## что такое client id

внутри soundcloud есть **идентификатор**, который их сайт использует чтобы **запрашивать** данные. aether **использует тот же** идентификатор.

**он периодически меняется** со стороны soundcloud. aether обновляется вместе с ним.

**если стриминг перестал работать** — скорее всего **идентификатор сменился**. решение — **дождаться обновления aether** или, если умеешь, **обновить вручную** (см. ниже).

## если что-то не работает

**симптом:** треки **не играют**, поиск **не работает**, всё **пусто**.

**что делать:**

1. открой `soundcloud.com` в браузере — **сайт работает?**
2. если **сайт работает**, а aether **нет** → **идентификатор сменился**
3. подожди **обновления** aether — разработчик обычно **выпускает быстро**

**если хочешь обновить сам:**

1. спроси в t.me/iqaether

## ограничения

**стриминг работает стабильно**, но есть **технические ограничения:**

- **задержка** перед стартом трека — 0.5-2 секунды. aether **скачивает** трек (полностью или **фрагментами**), потом **играет**. это **не** мгновенный стриминг как на сайте.
- **некоторые треки недоступны** — если soundcloud **не даёт** к ним доступ без аккаунта, или они **удалены** автором
- **треки удаляются** — если автор **удалил** трек, aether его **не найдёт** после **перезапуска**

## чего aether НЕ делает

- **не сохраняет** треки **на диск**
- **не обходит** платные функции soundcloud
- **не даёт** скачивать музыку
- **не работает** без интернета

**все треки воспроизводятся «на лету»** — как на сайте soundcloud.

## про законность

aether использует **публично доступные** данные soundcloud. **неофициальный клиент**, **не связан** с soundcloud.

**используй на свой риск.** если soundcloud **попросит** удалить проект — он будет **удалён**.

**не для коммерции.** проект **бесплатный**, **без рекламы**, **без подписок**.

## поддержка других источников

сейчас — **только soundcloud**.

**в планах:** spotify, youtube music и другие **аудио-хостинги**. точных **сроков нет**.

## где что искать

- **«не играет»** → см. «если что-то не работает»
- **«медленно стартует»** → норма, **0.5-2 сек**
- **«трек пропал»** → **автор удалил** его на soundcloud
- **«можно ли слушать spotify»** → пока **нет**, в планах
