# сборка

как запустить в режиме разработки и как собрать релиз.

## требования

- **node.js** 18+ — для фронта
- **rust** — для бэка (см. [rustup.rs](https://rustup.rs/))
- **windows** — для сборки `.msi` и `.exe` (linux/macos собираются **нативно**, но кросс-сборка не работает)

## bat-файлы

в корне проекта **три скрипта**:

| файл | что делает |
| :--- | :--- |
| `dev.bat` | запуск в режиме разработки |
| `build.bat` | релизная сборка |
| `fast-build.bat` | быстрая сборка для тестов |

**запуск** — двойной клик в проводнике, или `start dev.bat` в cmd.

## разработка

```
dev.bat
```

**что происходит:**
1. запускается **vite dev-сервер** (localhost:1420) — фронт
2. запускается **tauri** — окно приложения подключается к dev-серверу
3. открывается окно aether

**горячий релоад:**
- изменения в **tsx / ts / css** — видны **сразу**
- изменения в **rust** — **перезапуск** приложения (tauri сам пересоберёт)

## релизная сборка

```
build.bat
```

**что происходит:**
1. `tsc` проверяет типы (если ошибка — сборка останавливается)
2. `vite build` собирает фронт в `dist/`
3. `cargo build` (профиль `release`) собирает rust
4. tauri **бандлит** всё в `.msi` и `.exe`

**время:** первый раз **5-10 минут**, потом быстрее (**кэш** компиляции).

**результат:**

```
src-tauri/target/release/bundle/msi/aether_0.1.1_x64_en-US.msi
src-tauri/target/release/bundle/nsis/aether_0.1.1_x64-setup.exe
```

`0.1.1` — текущая версия из `tauri.conf.json`.

## быстрая сборка (для тестов)

```
fast-build.bat
```

собирает с профилем **`release-fast`** — те же артефакты, но **в 2 раза быстрее**. **чуть менее оптимизирован**. для **тестов** — идеально, для **релиза** — используй `build.bat`.

## установка

1. скачать `.msi` или `.exe` из [releases](https://github.com/whyspurky/aether-react/releases)
2. запустить — установщик сам поставит
3. ярлык появится в пуске

**`.exe` (NSIS)** — быстрый инсталлятор.
**`.msi` (WiX)** — стандартный для windows.

**размеры** — **~5 МБ** каждый. tauri **не тащит** chromium — использует **системный webview2** (есть в windows 10/11).

## скорость сборки

**первая сборка** — **5-10 минут**. компилируется **~200 зависимостей** rust.

**последующие** — **1-3 минуты** если ничего не менялось в rust.

**если менял только tsx** — секунды, rust не пересобирается.

**sccache** — кэш компиляции. если настроен — сильно ускоряет повторные сборки. **опционально**, в исходниках **не идёт**.

## частые проблемы

**`error: cannot find icon.ico`**
- `src-tauri/icons/icon.ico` **не настоящий ico**, а png переименованный
- **фикс:** `npm run tauri icon` (сгенерирует все форматы из одной png)

**`npm run build` падает с ts-ошибкой**
- `tsc` **строгий** — unused vars / unused imports
- смотри **сообщение** — там указан файл и строка

**`.msi` не появился после сборки**
- смотри `src-tauri/target/release/bundle/`
- если **пусто** — bundling упал раньше, смотри **ошибки выше** в выводе

**приложение не запускается**
- проверь **webview2** установлен ли (в windows 10+ по умолчанию есть)
- если нет — скачать [с сайта microsoft](https://developer.microsoft.com/microsoft-edge/webview2/)
