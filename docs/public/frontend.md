## точка входа

### main.tsx

монтирует `<App/>` в `#root`. всё.

### App.tsx

**три задачи:**

1. **роутинг** — `BrowserRouter` + `Routes`
2. **titlebar** — рендерится **всегда**, вне роутера
3. **инициализация** — при старте:
   - `useTheme()` — применяет цвета
   - `api.setVolume(volume)` — синхронизирует громкость с rust
   - `preloadHomePageData()` — прогревает популярное и мою волну

**роуты:**

| путь | страница |
| :--- | :--- |
| `/` | главная |
| `/search` | поиск |
| `/library` | библиотека |
| `/player` | полноэкранный плеер |
| `/artist/:id` | артист |
| `/playlist/:id` | плейлист |
| `/settings` | настройки |

**contextmenu отключён** на всём приложении (правый клик не работает).

### Layout.tsx

**обёртка** всего ui:

```
┌─────────┬──────────────────────────┐
│         │                          │
│ sidebar │       страница           │
│         │       (роутер)           │
│         │                          │
│         ├──────────────────────────┤
│         │     playerbar (если      │
│         │     есть трек и не на    │
│         │     /player)             │
└─────────┴──────────────────────────┘
```

**playerbar скрывается** на `/player` — там полноэкранный плеер.

## страницы

### HomePage (`/`)

**две колонки:**
- слева — **моя волна** (вертикальный список рекомендаций)
- справа — **популярное** (горизонтальная лента карточек)

**загрузка:** при первом входе. если уже загружено (флаг в сторе) — берётся **из памяти**. **пагинация** при скролле (популярное).

### SearchPage (`/search`)

**поиск** с **задержкой 500ms** (debounce). фильтр: **треки** / **артисты**.

**бесконечный скролл** — при приближении к низу подгружается **следующая порция**.

**клик по треку** — `playTrack` + переход в плеер.

**клик по артисту** — переход на его страницу.

### PlayerPage (`/player`)

**полноэкранный плеер:**
- обложка с **анимацией** смены трека
- название + автор
- прогресс-бар с **сиком** (drag)
- кнопки: shuffle / prev / play-pause / next / repeat
- громкость (горизонтальный слайдер)
- очередь треков снизу

### LibraryPage (`/library`)

**три вкладки:**
- **избранное**
- **история**
- **плейлисты** (в сайдбаре — список иконок)

**плейлисты:**
- создать (кнопка «+»)
- переименовать
- удалить
- посмотреть треки

**очистка** — через модалку подтверждения.

### SettingsPage (`/settings`)

**четыре вкладки:**
- **данные** — очистить историю / избранное / всё
- **внешний вид** — описание темы, палитра
- **диагностика** — кнопка «битые треки» (модалка)
- **о приложении** — название, версия, ссылка

### ArtistPage (`/artist/:id`)

профиль артиста: аватар, имя, счётчик подписчиков, треки.

**ограничение:** грузится через **треки артиста** — если у артиста **нет треков**, страница **не покажет** профиль.

### PlaylistPage (`/playlist/:id`)

отдельная страница для плейлиста. **сейчас не используется** — плейлисты открываются **встроенно** в `LibraryPage`. роут и компонент **есть** — на будущее.

## компоненты

### Layout / TitleBar / Sidebar

**каркас** приложения. TitleBar — **своя полоса** сверху (окно без системных decorations). Sidebar — **навигация слева**.

### PlayerBar

**мини-плеер** внизу. обложка + анимированное имя + кнопки + слайдер громкости.

**всё из стора** — пропсов нет.

### VolumeSlider

**вертикальный слайдер** громкости в поповере. открывается при наведении. **задержка 1 сек** перед скрытием — чтобы юзер мог вернуть мышь.

### AnimatedTrackInfo

имя трека + автор с **анимацией** при смене. старый текст **уезжает**, новый **приезжает** справа.

### TrackCard

карточка трека **для горизонтальной ленты** (в HomePage). обложка + имя + автор. при hover — кнопка **«+» в очередь**.

### TrackList

**вертикальный список** треков. нумерация слева. **если трек играет** — анимированный эквалайзер.

### Icon

рендерит **svg-иконку** по имени. все svg **инлайнятся** в бандл при сборке (не подгружаются **сетью**). если иконки нет — серый **пульсирующий** placeholder.

### HorizontalScroll

**горизонтальный скролл** с **плавным wheel** (колёсико → вправо/влево).

### Toast

всплывашка снизу. **иконка зависит от типа** (success / error / info). автоскрытие через **4 сек**.

### Modals

**ConfirmModal** — универсальное подтверждение. **Escape** закрывает.

**BrokenTracksModal** — список треков, которые не смогли воспроизвестись. **фича не подключена** — никто **не пишет** туда.

## состояние (zustand)

**`store.ts`** — **всё** в одном объекте. разделы:

- **`search`** — query + filter (сохраняется между заходами)
- **`queue`** — треки + текущий индекс
- **`homePage`** — популярное + моя волна + флаги
- **`player`** — играет/пауза, громкость, позиция, текущий трек
- **`library`** — избранное, история, плейлисты
- **`toast`** — текущий тост
- **`preload`** — флаг автоподгрузки

**сохранение** — **zustand persist** в `localStorage`. при **старте** восстанавливается:
- громкость, shuffle, repeat
- избранное, история, плейлисты
- **текущий трек** + позиция
- очередь

**следствие:** после перезапуска **видишь** трек в `PlayerBar`, **при нажатии play** — продолжает **с того же места**.

**основные экшены плеера:**
- **`playTrack`** — запускает трек: получает url, играет, ставит интервал позиции
- **`nextTrack` / `prevTrack`** — переход
- **`togglePlay`** — пауза/плей
- **`setVolume` / `setPosition`** — громкость / сик
- **`preloadMoreTracks`** — догружает очередь когда близко к концу

## стили

**все цвета — через css-переменные.** задаются из `theme.ts` → `useTheme` → `:root`. tailwind мапит их на классы (`bg-bg-primary`, `text-text-secondary` и т.д.).

**одна тема** — amoled. **задел** на будущие.

**фирменный стиль hover** — **инверсия**: фон становится цветом текста, текст — цветом фона.

```
bg-bg-secondary text-text-secondary
  hover:bg-text-secondary hover:text-bg-primary
```

## где что искать

- **«не переходит на страницу»** → `App.tsx` → роуты
- **«playerbar не показывается»** → `Layout.tsx` → условие рендера
- **«иконки не работают»** → `Icon.tsx` → `import.meta.glob`
- **«трек не играет по клику»** → `TrackCard` / `TrackList` → `playTrack` в сторе
- **«не сохранилась громкость»** → `App.tsx` → `api.setVolume` при старте
- **«не работает сик»** → `PlayerPage.tsx` → drag / `setPosition`
