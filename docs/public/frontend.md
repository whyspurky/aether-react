## точка входа

### main.tsx

монтирует `<App/>` в `#root`. плюс - `window.addEventListener('beforeunload', ...)` для остановки звука при `Ctrl+R`.

### App.tsx

**три задачи:**

1. **роутинг** - `BrowserRouter` + `Routes`
2. **titlebar** - рендерится **всегда**, вне роутера
3. **инициализация** - при старте:
   - `useTheme()` - применяет цвета
   - `applyProxy()` - устанавливает прокси из store (если выбран)
   - `api.setVolume(volume)` - синхронизирует громкость с rust
   - `preloadHomePageData()` - прогревает популярное и мою волну

**роуты:**

| путь | страница |
| :--- | :--- |
| `/` | главная |
| `/search` | поиск |
| `/library` | библиотека |
| `/player` | полноэкранный плеер |
| `/artist/:id` | артист |
| `/playlist/:id` | плейлист |
| `/settings` | настройки |

**contextmenu отключён** на всём приложении.

### Layout.tsx

**обёртка** всего ui:

```
______________________________________
│         │                          │
│ sidebar │       страница           │
│         │       (роутер)           │
│         │                          │
│         ----------------------------
│         │     playerbar (если      │
│         │     есть трек и не на    │
│         │     /player)             │
--------------------------------------
```

`playerbar` **скрывается** на `/player` - там полноэкранный плеер. Анимация ухода - `playerbar-exit` (уезжает вниз за 150ms). При появлении - `playerbar-enter`.

## страницы

### HomePage (`/`)

**две колонки:**
- слева - **моя волна** (вертикальный список рекомендаций)
- справа - **популярное** (горизонтальная лента карточек)

**загрузка:** при первом входе. если уже загружено (флаг в сторе) - берётся **из памяти**.

**скелетоны** - с рандомной шириной названий/артистов.

### SearchPage (`/search`)

**поиск** с **задержкой 500ms** (debounce). фильтр: **треки** / **артисты**.

**бесконечный скролл** - при приближении к низу подгружается **следующая порция**.

**клик по треку** - `playTrack` (весь список начиная с кликнутого).

**клик по артисту** - переход на его страницу.

**скелетоны** - разные для треков и артистов (квадратные обложки vs круглые аватарки).

### PlayerPage (`/player`)

**полноэкранный плеер:**
- обложка с **анимацией** смены трека (старая уезжает влево, новая приезжает справа)
- название + автор (адаптивный размер шрифта)
- прогресс-бар с **сиком** (drag мышью и тачем)
- кнопки: shuffle / prev / play-pause / next / repeat
- громкость (горизонтальный слайдер)
- очередь треков снизу

**effectiveDuration** - fallback на `currentTrack.duration / 1000`, если `player.duration === 0` (после холодного старта из persist).

### LibraryPage (`/library`)

**три вкладки:**
- **избранное**
- **история**
- **плейлисты** (в сайдбаре - список иконок)

**плейлисты:**
- создать (кнопка «+»)
- переименовать
- удалить
- посмотреть треки

**очистка** - через модалку подтверждения (`ConfirmModal`).

### SettingsPage (`/settings`)

**пять вкладок:**
- **данные** - очистить историю / избранное / всё
- **внешний вид** - описание темы, палитра
- **прокси** - режимы: выключен / встроенный (в разработке) / личный (SOCKS5/HTTP) / запрет (zapret)
- **диагностика** - кнопка битые треки
- **о приложении** - название, версия (через `getVersion()`), ссылка

**индикатор** - зелёная точка рядом с вкладкой «прокси» если zapret работает. обновляется каждые 5 сек.

### ArtistPage (`/artist/:id`)

профиль артиста: аватар, имя, счётчик подписчиков, треки.

**ограничение:** грузится через треки артиста. если у артиста нет треков - страница не покажет профиль.

### PlaylistPage (`/playlist/:id`)

отдельная страница для плейлиста. **сейчас не используется** - плейлисты открываются **встроенно** в `LibraryPage`. роут и компонент есть на будущее.

## компоненты

### Layout / TitleBar / Sidebar

Layout - **каркас** приложения. TitleBar - **своя полоса** сверху (окно без системных decorations). Sidebar - **навигация слева**.

**Sidebar** - подсветка снизу вверх при hover/active (через `origin-bottom` + `scale-y`). Иконка уменьшается при клике (`group-active:scale-90`).

### PlayerBar

**мини-плеер** внизу. обложка + анимированное имя + кнопки + слайдер громкости.

**всё из стора** - пропсов нет.

**прогресс-бар** - тонкая полоска внизу. при hover растёт до 3px. при drag - остаётся большой. клик и drag работают.

### VolumeSlider

**вертикальный слайдер** громкости в поповере. открывается при наведении. grace period 1 сек перед скрытием - чтобы юзер мог вернуть мышь.

### AnimatedTrackInfo

имя трека + автор с **анимацией** при смене. старый текст уезжает, новый приезжает справа.

### TrackCard

карточка трека **для горизонтальной ленты**. обложка + имя + автор. при hover - кнопка «+» в очередь.

**имя артиста кликабельно** - переход на страницу артиста (клик по имени не запускает трек).

### TrackList

**вертикальный список** треков. нумерация слева. если трек играет - анимированный эквалайзер (eqBar).

**имя артиста кликабельно** - переход на страницу артиста.

### Icon

рендерит **svg-иконку** по имени. все svg **инлайнятся** в бандл при сборке (`import.meta.glob` с `?raw`). если иконки нет - серый пульсирующий placeholder.

### HorizontalScroll

**горизонтальный скролл** с **плавным wheel** (`scrollLeft` + `requestAnimationFrame` + `easeOutCubic`).

### ProxySettings.tsx

**настройки прокси и обхода блокировок.**

**режимы:**
- **выключен** - прямое соединение
- **встроенный** - заглушка, не реализовано
- **личный** - `SOCKS5` / `HTTP` / `HTTPS`, юзер вводит адрес xray/sing-box. аэтер применяет через `proxy_set_custom`
- **запрет (zapret)** - управление утилитой zapret:
  - скачивание автоматически с github
  - выбор папки (нативный диалог через `tauri-plugin-dialog`)
  - список стратегий `general*.bat` (натуральная сортировка)
  - запуск/остановка, блокировка выбора пока работает
  - проверка `list-general-user.txt` на домены soundcloud
  - кнопка «добавить soundcloud» - добавляет 20 доменов
  - прогресс скачивания в реальном времени

**прогрев** - после запуска стратегии каждые 5 секунд дёргается `proxy_test`, пока `cdn` не ответит ok. максимум 30 сек - потом надо менять стратегию.

### проверка подключения

в разделе «прокси» сверху - кнопка «проверить». **api** и **cdn** проверяются **параллельно**, результат показывается по мере готовности. **api** обычно отвечает за 100-300ms, **cdn** - за 200-500ms (если вообще работает).

### Toast

всплывашка снизу. **иконка зависит от типа** (success/error/info). автоскрытие через **4 сек**.

### Modals

**ConfirmModal** - универсальное подтверждение. **Escape** закрывает.

**BrokenTracksModal** - список треков, которые не смогли воспроизвестись. **фича не подключена** - никто не пишет в `aether_broken_tracks`.

## состояние (zustand)

**`store.ts`** - **всё** в одном объекте. разделы:

- **`search`** - query + filter
- **`queue`** - треки + текущий индекс + source
- **`homePage`** - популярное + моя волна + флаги
- **`player`** - играет/пауза, громкость, позиция, текущий трек, `pendingSeek`
- **`library`** - избранное, история, плейлисты
- **`proxy`** - режим + custom прокси + zapret (папка, статус, batPath)
- **`toast`** - текущий тост
- **`preload`** - флаг автоподгрузки

**сохранение** - **zustand persist** в `localStorage` под ключом `aether-storage`. при **старте** восстанавливается:
- громкость, shuffle, repeat
- избранное, история, плейлисты
- текущий трек + позиция
- очередь
- настройки прокси (режим + custom + папка zapret)

**следствие:** после перезапуска видишь трек в `PlayerBar`, при нажатии play - продолжает с того же места.

**основные экшены плеера:**
- **`playTrack`** - запускает трек: получает url, играет, ставит интервал позиции
- **`nextTrack` / `prevTrack`** - переход
- **`togglePlay`** - пауза/плей (с поддержкой холодного старта из persist)
- **`setVolume` / `setPosition`** - громкость / сик
- **`preloadMoreTracks`** - догружает очередь когда близко к концу

## стили

**все цвета - через css-переменные.** задаются из `theme.ts` - `useTheme` - `:root`. tailwind мапит их на классы (`bg-bg-primary`, `text-text-secondary` и т.д.).

**одна тема** - amoled. задел на будущие.

**фирменный стиль hover** - **инверсия**: фон становится цветом текста, текст - цветом фона.

**анимации:**
- `animate-page-in` - плавное появление страницы (fade-in + сдвиг 6px)
- `animate-content-fade-in` - появление контента после скелетонов
- `playerbar-enter` / `playerbar-exit` - выезд/уезд мини-плеера
- `eqBar` - эквалайзер в TrackList
- `animate-sidebar-indicator` - полоска активной вкладки в Sidebar
