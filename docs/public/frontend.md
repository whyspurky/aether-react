## точка входа

### main.tsx

монтирует `<App/>` в `#root`. всё.

### App.tsx

**три задачи:**

1. **роутинг** 
2. **titlebar** — рендерится **всегда**
3. **инициализация** — при старте:
   - `useTheme()` — применяет цвета
   - `api.setVolume(volume)` — синхронизирует громкость с rust
   - `preloadHomePageData()` — прогревает популярное и мою волну

### Layout.tsx

**обёртка** всего ui:

```
┌─────────┬──────────────────────────┐
│         │                          │
│ sidebar │       страница           │
│         │       (роутер)           │
│         │                          │
│         ├──────────────────────────┤
│         │     playerbar (если      │
│         │     есть трек и не на    │
│         │     /player)             │
└─────────┴──────────────────────────┘
```

## страницы

### HomePage (`/`)

**две колонки:**
- слева — **моя волна** (вертикальный список рекомендаций)
- справа — **популярное** (горизонтальная лента карточек)

**загрузка:** при первом входе. если уже загружено — берётся **из памяти**

### SearchPage (`/search`)

**поиск** фильтр: **треки** / **артисты**

**бесконечный скролл** — при приближении к низу подгружается **следующая порция**

**клик по треку** — `playTrack`

**клик по артисту** — переход на его страницу

### PlayerPage (`/player`)

**полноэкранный плеер:**
- обложка с **анимацией** смены трека
- название + автор
- прогресс-бар с сиком
- кнопки: shuffle / prev / play-pause / next / repeat
- громкость
- очередь треков снизу

### LibraryPage (`/library`)

**три вкладки:**
- **избранное**
- **история**
- **плейлисты**

**плейлисты:**
- создать
- переименовать
- удалить
- посмотреть треки

**очистка**

### SettingsPage (`/settings`)

**четыре вкладки:**
- **данные** — очистить историю / избранное / всё
- **внешний вид** — описание темы, палитра
- **диагностика** — кнопка битые треки (модалка)
- **о приложении** — название, версия, ссылка

### ArtistPage (`/artist/:id`)

профиль артиста: аватар, имя, счётчик подписчиков, треки

## компоненты

### Layout / TitleBar / Sidebar

Layout - **каркас** приложения. TitleBar — **своя полоса** сверху Sidebar — **навигация слева**

### PlayerBar

**мини-плеер**

### VolumeSlider

**вертикальный слайдер** громкости открывается при наведении

### AnimatedTrackInfo

имя трека + автор с **анимацией** при смене старый текст **уезжает**, новый **приезжает** справа

### TrackCard

карточка трека **для горизонтальной ленты**. обложка + имя + автор

### TrackList

**вертикальный список** треков нумерация слева **если трек играет** — анимированный эквалайзер

### Icon

рендерит **svg-иконку** по имени. все svg **инлайнятся** в бандл при сборке

### HorizontalScroll

**горизонтальный скролл** с **плавным wheel** 

### Toast

всплывашка снизу. **иконка зависит от типа**. автоскрытие через **4 сек**.

### Modals

**ConfirmModal** — универсальное подтверждение. **Escape** закрывает.

**BrokenTracksModal** — список треков, которые не смогли воспроизвестись. **фишка еще не подключена**

## состояние (zustand)

**`store.ts`** — **всё** в одном объекте. разделы:

- **`search`** — query + filter
- **`queue`** — треки + текущий индекс
- **`homePage`** — популярное + моя волна + флаги
- **`player`** — играет/пауза, громкость, позиция, текущий трек
- **`library`** — избранное, история, плейлисты
- **`preload`** — флаг автоподгрузки

**сохранение** — **zustand persist** в `localStorage` при **старте** восстанавливается:
- громкость, shuffle, repeat
- избранное, история, плейлисты
- **текущий трек** + позиция
- очередь

**основные экшены плеера:**
- **`playTrack`** — запускает трек: получает url, играет, ставит интервал позиции
- **`nextTrack` / `prevTrack`** — переход
- **`togglePlay`** — пауза/плей
- **`setVolume` / `setPosition`** — громкость / сик
- **`preloadMoreTracks`** — догружает очередь когда близко к концу
