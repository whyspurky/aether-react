# архитектура

как устроен проект в общих деталях

## что такое tauri

*tauri* это фреймворк для десктопных приложений

внутри одного процесса aether exe работают две части:

1. *webview* где рендерится весь ui на react

2. *rust* который делает всю тяжёлую работу

фронт общается с rust через *ipc* механизм tauri

фронт зовёт rust через *invoke*

rust ходит в soundcloud через *reqwest*

декодирование аудио целиком в rust через *rodio*

## почему аудио в rust

есть две причины

1. *web audio api* не умеет hls из коробки

2. soundcloud отдаёт треки *фрагментами*, это hls плейлисты

поэтому rust *скачивает* все сегменты, *склеивает* в память и *декодирует* через rodio

## старт приложения

что происходит при запуске по шагам

1. *persist* восстанавливает состояние из localStorage

2. *App tsx* рендерит *AppContent*

3. применяется *тема*, цвета становятся на свои места

4. применяется *прокси* если он выбран

5. прогревается *популярное* и *моя волна*

6. синхронизируется *громкость* с движком

## обход блокировок

aether работает в регионах где soundcloud заблокирован

есть два механизма

### первый личный прокси

1. aether создаёт http клиент с настройками прокси

2. весь трафик идёт через прокси

3. юзер сам поднимает xray или sing box

4. aether просто направляет трафик

### второй zapret

внешняя утилита которая перехватывает пакеты и модифицирует их так что dpi пропускает

aether управляет ею по шагам

1. *скачивает* последний релиз с github

2. *распаковывает* в локальную папку

3. *находит* вложенную папку со стратегиями

4. *запускает* выбранную стратегию

5. *следит* за статусом

6. *добавляет* домены soundcloud в списки обхода

## ключевые концепции

### tauri команды

фронт не может напрямую звать rust
только через команды

1. фронт просит rust выполнить что то

2. rust выполняет и возвращает результат

### hls стриминг

soundcloud отдаёт некоторые треки не одним файлом а *плейлистом фрагментов*

rust *скачивает* все сегменты параллельно, *склеивает* в память, потом *декодирует* в звук

почему так
soundcloud не даёт прямой mp3 для всех треков
где даёт, играем mp3 напрямую
где только hls, качаем целиком

### zustand persist

состояние сохраняется в localStorage под ключом *aether storage*

при старте восстанавливается

1. громкость shuffle repeat

2. избранное история плейлисты

3. текущий трек и позиция

4. очередь

5. настройки прокси

### pendingSeek

механизм сика до старта

если юзер двигает ползунок до того как трек заиграл, позиция сохраняется в *pendingSeek* и применяется после старта

### async в rust

1. все http операции *async* через tokio

2. параллельная загрузка hls через *futures stream buffered*
